# 成稿外挂词表

和 [kb/](../kb/INDEX.md) 不是同一库。`kb/` 管开发怎么停、怎么写给 agent；这里管**越来越像园主**。

成稿、润色经验稿时打开 [lexicon.md](lexicon.md)，只抽对得上的词和联想。不要整本搬，不要把 [ledger.md](ledger.md) 里的项目细节套到无关任务。闲聊、答问、纯工程短卡不读。

## 进库（维护）

触发：用户说「这篇进库」，或正式发且园主点头。草稿、未点头、别人的文章、只改标点的润色：不进。

1. 在 [ledger.md](ledger.md) 加一行：日期、指针（vault 或 `posts/<slug>`），**不贴全文**。
2. 从这篇抽出 3–8 个新词进 [lexicon.md](lexicon.md)。已有的不重复。每个词写：字面、在园主笔下是什么意思、什么场合用。
3. 联想 / 对比最多补 1–3 条。写「常拿什么跟什么比」，不要写成金句。
4. 同步：本目录在 tta-tone 真源里。改完用 `tta-sync-harness` 联接，不要拷 `SKILL.md`。

一次进库就停。不要为了丰富把通稿词（赋能、抓手、说人话版本）写进来。

## 读取

- 先 [canon.md](../canon.md) 和现场格子，再看词表。
- 词表是配料，不是模具。没有对得上的词就不用。
- 公开稿仍守 canon 忌口。
