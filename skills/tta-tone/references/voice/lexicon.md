# 惯用词和联想

从 [ledger.md](ledger.md) 里点过头的成稿抽出。学用法，不把那一篇的项目细节套到无关任务上。

## 黑话 / 惯用

| 词 | 在园主笔下 | 什么场合用 |
| --- | --- | --- |
| 猛蹬 | 长时间、高强度地用某个模型或额度池 | 时间线里「那段日子在干什么」 |
| 悄摸摸 | 官方不声张地上线或改了入口 | 发现正式版、开关被挪了 |
| 中门对狙 | 两家正面硬刚，不是旁敲侧击 | 两款模型或产品同一晚撞上 |
| 吃灰 | 买了、领了、下了，却一直没用 | 旧额度、旧设备突然有用 |
| 小园丁 | 公开稿对读者的称呼 | 请人进来看货的那一下 |
| 摊开揉碎 | 把配置或模块讲清楚，不卖关子 | 时间线和例子之后，开始拆货 |
| 名册过肥 | 技能或工具目录太多，模型只看见名字 | 讲 Skill / 工具暴露面 |
| 缝 | 配置没锁紧的地方，不是广告里的「挑战」 | 货摊开之后，放后面的表 |

## 联想 / 对比

- 额度池子（好用、耐用）对官方亲儿子通道（缓存、额度倍率）。
- ADE：任务、权限、终端、浏览器围着同一个 Agent，对「只是套了个壳的聊天窗」。
- 工具越强，路径、名册、上下文纪律的缝越显眼；马甲重要，自己把这三样管住更重要。

不要把「说人话版本」「我踩过的坑」收进来。那是忌口，见 [canon.md](../canon.md)。
