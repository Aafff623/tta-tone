# 交给路由器

## 机制

对方卡在「下一步该调哪份本机开发 Skill / 当前不知道要干嘛」时，tta-tone 只接处境，再把选型交给 `ask-matt`（Codex `$ask-matt`）。那份只能提示，不能替人开火。阶段停点问法由它打开自带的 `PHASE-BOUNDARIES.md`。大雾画地图是另一份，不要当成这份。

## 开火

不知道该怎么办。不知道用哪份 Skill。懵了该走哪条流程。问的不是怎么写稿、怎么讲模块。

## 怎么叠判断四问

- 依据：对方这轮有没有已经选定成稿或讲授。
- 对立：tta-tone 自己从目录里挑一份；把大雾画地图当成路由器。
- 这轮：写出 `ask-matt`（Codex `$ask-matt`），按它自己的步骤走。
- 保护：不要把目录抄进本 Skill。

## 不接什么

已经选定怎么写稿或怎么讲模块。把九份开发 Skill 糊进开口。把 `wayfinder` 当成这份路由器。
