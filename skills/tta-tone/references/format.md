# 排版（Markdown 编排）

文风管句子，这一篇管版面。规律全部抽自 vault 已发布稿（ZCode 金样本、Claude Code 完全手册、VelaTerm 四连修、修仙人格稿），对照时打开原文看编排骨架，不要抄内容。改别人的稿：原稿已有编排一律保留；新稿按这里排。

## 段落和续行

1. 正文段落之间空一行，一个自然段说一件事。
2. 段内换行有两种写法，都是「同一逻辑段连排」，不是新段落：行尾两个空格（金样本风，前言里「一边是……一边是……」那段）；或下一行 tab 缩进（完全手册风，定义句下挂例子）。同一篇选一种为主。
3. 空行只属于：段与段之间、标题上下、表格 / 代码块 / 引用块前后。不用空行做节奏渲染。

## 标题与分节

1. 正文第一行不重复整篇 H1。
2. 大章用中文数字：`## 一、二、三、`，章名写成「对象：白话点题」（`## 二、思考状态行花字：宽度对齐的本质`）。
3. 条目化子模块用阿拉伯数字：`#### 1. Skills：把反复粘贴的东西变成一条命令`。同一篇里中文数字管章、阿拉伯数字管条，不混层。
4. 没有标题可起的转场用 `---` 横线；有标题就不用横线。人格口播稿常不用横线，靠章号就够。
5. 标题只说明这一节是什么，不写个人待办式节名。

## 加粗

1. 术语首次定义加粗（`**渐进加载**`、`**箓籍**`、`**阳间**`），同一术语全文只加粗第一次。
2. 每节最多一两句承重判断整句加粗，加粗就真承重；人格稿的金句多走「tab 续行 + 加粗」独立成行。
3. 列表项领起语加粗：`1) **Explore**（只读快速研究代码库）`。
4. 更新 / 勘误块的标签加粗带日期：`> **2026-08-09 实测更新**：……`。
5. 不拿加粗当行高亮；整段加粗、连续多句加粗是拐棍（lint 超 5 处会 WARN）。

## 引用块

1. 引文层用 `> _**……**_`（斜体 + 粗体）：经典原文、故事台词、开篇题旨句。引文后紧跟一段白话解释（「意思是说……」），解释在框外。
2. 金句独立成块用 `> **……**`（不斜体）：一句承重话值得单独站一行时用。
3. 引语（原话、报错、官方说法）用裸引用块 `> ……`，判断写在框外，引用不当第一句。
4. 事后补记 / 勘误用 `> **日期 + 实测更新**：` 领起，放进正文流里不新开节。
5. 引用块不代替强调：框里放别人的话或事后补记，不放自己的正文判断。

## 列表和序号

1. 步骤、有先后或有权重的并列，用 `1. 2. 3.`。
2. 冒号领起句后面的紧凑说明枚举，用 `1) 2)`：「几个控制项值得记：1) ……；2) ……」。它贴着上一句，属于那句话的展开。
3. 无序并列（例子、来源、特征）用 `- `。
4. 列表能改回自然段时优先改回（「调用方式有四种：」直接连排就是样子）。列表只给真并列。
5. 同一层不混序号样式；对照块用两个并列段落，不硬塞进一套列表。

## 补充行

定义或判断段的下面，例子和推论可以用 tab 缩进行挂在段下（「比如你在……」「这意味着你……」）：渲染时还是那个段落，版面上脱离正文流。一段最多一两行；笔记体、素材卡可以放宽，读者成稿收紧。

## 图片和表格

1. 图片紧跟它解释的段落，下一行就放，前面不空行；alt / 文件名写说明句。
2. 表格管密度货：参数、入口、对照、缝。表格前一句人话领起（「我习惯把扩展面分成五块：」），表格后接回正文，不让表格裸收尾。
3. 路径、命令、配置名一律行内代码。

## 完成验证

排完通读一遍：标题层级一致、加粗真承重、引用块里是别人的话、列表真并列、图片锚在解释它的段落后面。版面错不算润色失手，算稿子没写完。
