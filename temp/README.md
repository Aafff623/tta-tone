# Local temp workspace

This directory holds ignored project-local material. It follows the `tta-init` temp model:

- `references/sources/`: cloned upstream/reference repositories used for comparison.
- `reports/`: research and validation reports.
- `handoff/`: task handoffs and continuation notes.
- `scripts/`: disposable local scripts.
- `logs/`: command and test logs.
- `preview/`: local previews and rendered artifacts.
- `secrets/`: explicitly received credentials for local use; never commit or echo them.

Only this file and `temp/AGENTS.md` are tracked. Payloads below `temp/` are ignored.
